⚙️ Helm Help

What is Helm?

Helm is your productivity dashboard. View, add, complete, and organize tasks synced with your MCP server.

Task Sections

SectionColorMeaning
📥 IncomingPurpleTasks from teammate — Claim or Complete
🎯 ActiveGreenYour current focus
⚠️ OverdueRedPast due date
📌 Sprint QueueOrangeIn sprint but not active
📋 BacklogGrayEverything else by category

Task Actions

ButtonWhat It Does
★ ActivateMove to Active section
− RemoveRemove from Active (back to backlog)
✓ DoneComplete the task
✓ ClaimAccept incoming task from teammate

Adding Tasks

Use the input box at the top: Type task → Select category → Check "Active" if needed → Click Add or Enter
