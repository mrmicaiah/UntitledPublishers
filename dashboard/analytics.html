🔗 Connect Google Analytics

To see your blog analytics, connect Google Analytics and add your GA4 property.

1 Enable API
Enable Google Analytics Data API in Google Cloud Console
2 Connect Service
In Claude: connect_service google_analytics
3 Add Property
analytics_add_property property_id="..." name="My Blog"
