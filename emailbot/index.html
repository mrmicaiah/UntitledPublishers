📧 Courier Help

What is Courier?

Courier is your email marketing platform. Manage subscriber lists, create email templates, set up automated sequences, and send campaigns.

Tabs Overview

TabPurpose
📊 StatsOverview of subscribers, lists, and recent activity
📋 ListsCreate and manage email lists
👥 SubscribersView and manage all subscribers
🔄 SequencesAutomated email series
📝 TemplatesReusable email designs
✉️ CampaignsOne-time email sends

Creating a List

  1. Go to Lists tab
  2. Click + New List
  3. Enter name (slug auto-generates)
  4. Set From Name and From Email
  5. Save

Setting Up a Sequence

  1. Go to Sequences tab
  2. Click + New Sequence
  3. Name it and select which list triggers it
  4. Save, then click Steps
  5. Add emails with delays (in minutes)
💡 Example: Step 1 at 0 min (welcome), Step 2 at 1440 min (1 day later)

Sending a Campaign

  1. Go to Campaigns tab
  2. Click + New Campaign
  3. Select list (or "All Subscribers")
  4. Write subject and body
  5. Save as Draft → Click Send

Template Variables

VariableReplaced With
